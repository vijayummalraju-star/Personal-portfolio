# Vijay Ummalraju — Personal Portfolio

Welcome to my personal portfolio! 🚀

This website showcases my profile, skills, projects, journey, and selected work through an interactive React experience.

## ✨ Highlights

- Modern interactive portfolio built with React + TypeScript
- Responsive design for desktop and mobile
- Animated hero and visual sections
- Project showcase and gallery
- Personal journey/timeline section
- Interactive UI components and effects
- Personal profile image included in `public/uploads/vijay.png`

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- CSS
- Supabase integration

## 📁 Project Structure

```text
Personal-portfolio/
├── api/                  # API/serverless functions
├── public/               # Static assets
│   └── uploads/          # Profile and uploaded media
├── src/
│   ├── assets/           # Project assets
│   ├── components/       # Portfolio UI components
│   ├── lib/              # External service configuration
│   ├── App.tsx           # Main application
│   ├── App.css           # App styles
│   ├── index.css         # Global styles
│   ├── hooks.ts          # Custom hooks
│   └── main.tsx          # Application entry point
├── package.json
├── vite.config.ts
└── tsconfig.json
```

## 🚀 Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

## 🔐 Environment Variables

Keep API keys and service credentials out of the repository. Configure required environment variables through your local environment or deployment platform.
